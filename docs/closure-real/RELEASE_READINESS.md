# Preparación para producción

**NO-GO / no aprobado para publicar.** Esta tarea no autoriza despliegues ni APK release.

Antes de solicitar aprobación se requiere: completar A–H sobre API QA compartida, ejecutar y evidenciar NAV faltantes, repetir todo en los SHA finales, revisar paridad de campos, verificar versiones y compatibilidad de migraciones, y confirmar una ruta de rollback. La compilación debug de QA no es una APK release ni prueba de firma/publicabilidad.
